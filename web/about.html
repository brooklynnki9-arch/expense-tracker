About this project

How it started

Expense Tracker began as a C++ console program I wrote while learning to code. It records income and expenses, sorts spending into categories, checks monthly budgets, and prints reports. This website is the same tracker, rebuilt with HTML, CSS, and JavaScript so anyone can use it in a browser.

Your privacy

Everything you type in the tracker is saved in your own browser using localStorage. Nothing is sent to a server, there are no accounts, and nobody else can see your data.

That also means your entries only live on the device and browser you used. If you clear your browser data or switch to another computer, you'll start with an empty tracker.

How it's built

  • HTML for the layout of each page
  • CSS for the colors and spacing, in one shared style.css file
  • JavaScript for the tracker itself (app.js) and the quick look on the home page (home.js)
  • GitHub Pages to host the site for free

The original C++ program and all of this website's code are on GitHub.
